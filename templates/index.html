04.1 / AI + ENGINEERING

AI-Assisted
Engineering Workflow

將 AI 輔助開發納入工程流程：從需求釐清、程式草稿到整合部署，每一步都由我定義方向、審查成果並驗證。
  1. 01

    Requirement Analysis

    釐清使用情境、工程限制與驗收標準，先確認要解決的問題。

  2. 02

    Requirement Breakdown

    將需求拆成可執行的任務，定義前端、後端與資料處理的範圍及相依關係。

  3. 03

    Prompt / Specification Design

    明確描述輸入輸出、介面規格與限制，讓 AI 依照工程需求產出草稿。

  4. 04

    AI-assisted Frontend / Backend Generation

    利用 AI 輔助建立 UI 草稿、基礎程式碼與後端結構，作為開發起點。

  5. 05

    Human Review & Engineering Validation

    由我審查程式邏輯、架構與工程規則，確認產出符合需求與限制。

  6. 06

    Iterative Debugging

    重現問題、檢查紀錄並評估 AI 的除錯建議；修正後反覆驗證。

  7. 07

    Frontend / Backend / Data Integration

    由我串接操作介面、API 與資料流程，確認格式、狀態及錯誤處理一致。

  8. 08

    Testing & Validation

    依驗收標準檢查功能、邊界條件與整合結果，確認系統行為符合預期。

  9. 09

    Git Version Control

    開發全程以 Git 記錄變更；發布前審查差異，保留可追溯與回復的版本。

  10. 10

    Deployment

    由我最終核准，確認環境設定後部署，並檢查上線後的主要功能。
